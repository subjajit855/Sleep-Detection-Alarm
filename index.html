Introduction

The Sleep Detection Alarm is a small safety device that detects a prolonged inactive, sleep-like condition and raises an alarm.

Detect

An IR sensor watches the area in front of it and reports to the Arduino Nano.

Decide

The Arduino checks whether the condition lasts for the programmed time.

Alert

If it does, the buzzer sounds. When normal returns, it stops.

Prototype limit. A basic FC-51 IR obstacle sensor cannot reliably tell whether a person is asleep. Reliable detection needs an eye-blink sensor or a camera system. This project shows how sensors, a microcontroller and an alarm work together.

How it works

Seven steps from power-on to reset.

  1. Power on

    The 9V battery feeds the Arduino Nano through VIN.

  2. Sensor detection

    The IR sensor continuously monitors the area in front of it.

  3. Signal processing

    The sensor sends a digital signal to pin D2.

  4. Condition checking

    The Arduino checks whether the condition continues for the set time.

  5. Alarm activation

    Past the set time, the Arduino drives pin D8.

  6. Alert

    The buzzer turns on and warns the user.

  7. Reset

    When the normal condition returns, the buzzer stops and monitoring continues.
